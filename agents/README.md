# agents/

One folder per agent role. Each holds that agent's instructions, context, task files and handoff notes.
Repo-wide rules are in the root `AGENTS.md`; an agent folder adds role-specific rules and never overrides them.

| Folder | Owns | Status |
|--------|------|--------|
| `android/` | `android/` app code | active |

Add a new role by copying `android/` and editing `AGENT.md`.
