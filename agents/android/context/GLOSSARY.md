# Glossary
- **EQO**: the product. Your voice comes back as action.
- **Agent loop**: prompt -> model -> parse tool calls -> run tools -> feed results back, until done.
- **Composio**: hosted service handling OAuth and execution for 1000+ app toolkits.
- **LiteRT**: Google's on-device runtime used to run Gemma.
- **Fact extraction**: LLM pass that turns conversation into durable memory rows.
