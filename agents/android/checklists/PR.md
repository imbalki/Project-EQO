# PR checklist (Android)
- [ ] Task file and `tasks/INDEX.md` status updated
- [ ] `./gradlew ktlintCheck detekt test` passes locally
- [ ] Tests added for new logic
- [ ] No secrets, keys or personal data in code, logs or tests
- [ ] New permissions or dependencies justified in the PR description
- [ ] Screenshots or screen recording for UI changes
- [ ] Works with cloud OFF (default path)
